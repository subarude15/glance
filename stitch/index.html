punk & rally

Static design export for Google Stitch. Sample data only — no secrets, no private IPs. Theme follows OS light/dark.

how to use in Stitch
  1. Import DESIGN.md from the repo root into a Stitch project (design rules).
  2. Open a mockup below, screenshot it, upload as a reference image in Experimental / Pro mode.
  3. Paste a prompt from PROMPTS.md and iterate.
  4. Optional: if this folder is on a public URL, ask Stitch to extract the design system from that URL.
